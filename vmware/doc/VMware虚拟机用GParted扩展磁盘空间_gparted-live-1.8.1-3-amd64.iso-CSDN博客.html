VMware虚拟机用GParted扩展磁盘空间

虚拟机磁盘扩容用GParted工具非常方便，但是我的虚拟机无法联网，因此不能直接用 命令 行安装GParted，因此去官网下载了一个GParted Live ISO文件，扩展磁盘空间。

1.查看可用空间大小

打开虚拟机，在终端输入命令： sudo fdisk -l ,查看当前磁盘分区情况。可以看到设备列表下有3个，sda1、sda2、sda5，sda5的大小有59.5G。

sudo fdisk -l
bash

在终端输入命令：df -h，查看当前磁盘的可用空间。/dev/sda5的可用空间为6.1G，现在需要对其进行扩展。

df -h
bash

2.下载 GParted Live ISO

访问 GParted 官方下载页面：https://sourceforge.net/projects/gparted/，下载最新的 GParted Live ISO 文件：gparted-live-1.8.0-2-amd64.iso。

3.在 VMware 中扩展虚拟磁盘

首先关闭 Ubuntu 虚拟机，右键虚拟机 → 设置 → 选择硬盘，在扩展磁盘容量中选择‘扩展’，设置需要扩展的磁盘空间大小，这里扩展为70G，设置完成后，点击扩展。注意：此操作只会增加虚拟磁盘的“物理”容量，不会影响磁盘内的分区和数据。

4.挂载 GParted Live ISO 并设置从 光 盘启动

继续在设置中选择 CD/DVD (SATA) 或类似的光驱设备，设备状态选择：启动时连接，连接选择：使用IOS映像文件，并点击浏览，选择第2步中下载的ISO 文件：gparted-live-1.8.0-2-amd64.iso最后点击确认。

进入BIOS设置，调整启动顺序，确保虚拟机优先从光盘启动。进入BIOS的方式如下：点击虚拟机 -> 电源 -> 打开电源时进入固件。

进入BIOS设置之后，选择Boot，将CD-ROM Drive 的启动顺序调整到Hard Drive之前。点击F10保存设置并退出。

5.启动进入 GParted Live 环境

启动虚拟机，如果设置正确，你会看到 GParted Live 的启动菜单界面。选择默认选项 GParted Live (Default settings)即可。

之后会让你选择语言等，按需选择。

稍等片刻，系统会启动到一个图形界面，并自动打开 GParted 分区编辑器窗口。可以看到灰色的未分配区域，这就是第3步中扩展的磁盘区域。

6.使用 GParted 调整分区

现在需要把未分配区域增加到你需要的分区中，如/dev/sda5。由于sda5是sda2的子分区，因此需要先调整sda2的分区。点击/dev/sda2，点击上面的箭头符号：调整大小/移动。

在弹出的窗口中，用鼠标拖动分区右侧的箭头，将分区扩展到末尾，或直接在 新大小 输入框中填写总容量。设置完成之后点击 调整大小/移动。

之后再用同样的方式调整sda5的分区。调整完成之后如下图所示，此时 GParted 底部会有一个待执行的操作列表。点击工具栏上的 ✓ 应用所有操作 ，确认执行。等待操作完成（过程可能需要几分钟）。

7.完成并重启

所有操作应用成功后，关闭 GParted 窗口。点击桌面左上角的菜单（类似开始菜单），选择 Exit （双击）→ Shutdown 或 Reboot。

虚拟机重启之后，打开终端再次输入df -h命令查看磁盘空间大小，确认分区的磁盘空间已经增加。

最后可以重新打开BIOS设置，将启动顺序恢复为原来的顺序，CD-ROM Driver 在Hard Driver之后。
